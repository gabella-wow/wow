# Предметы из клиента Forever (GabellaGear 2)

Экипировка, расходники, реагенты и торговые товары из клиента; заодно таланты (GabellaTalents). Работает только через игровое API аддонов, ничего никуда не отправляет.

1. Скопировать папки `GabellaGear` и `GabellaTalents` (`tools/talent_dump`) в `C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\`.
2. В списке аддонов включить «Загружать устаревшие» (номер интерфейса Forever заранее неизвестен).
3. Персонажем в городе: `/ggd all`, дождаться «scan done» (3–5 минут), выйти. Это скан предметов и таланты этого класса за один заход. Ещё раз с английским текстом клиента (Battle.net → настройки игры → язык текста English): английские названия и строки «Equip:» нужны для разбора. Таланты: каждым из 9 классов `/gtd` (см. `tools/talent_dump/README.md`).
4. Источники копятся сами, пока аддон включён: добыча боссов в подземельях (труп босса в цели), награды в окне квеста, рецепты в открытом окне профессии.
5. Файл `_forever_\WTF\Account\<аккаунт>\SavedVariables\GabellaGear.lua` отдать в
   `python tools/gear_import.py --addon <файл>` → `data/gear30.json` (provenance `client-dump`), затем `python build.py`.
   Все предметы с иконками: `gear_import.addon_items(<файл>)`.

Команды: `/ggd all` · `/ggd scan` (оборвался — продолжит с места; `/ggd scan new` заново) · `/ggd scan A B` · `/ggd max N` (до какого требуемого уровня, по умолчанию 60) · `/ggd status` · `/ggd stop`.

Что сохраняется (`GabellaGearDB.items[id]`): `name{локаль}`, `slot` (INVTYPE_*, у расходников нет), `ilvl`, `req`, `q`, `icon` (file id), `iclass`/`isub` (класс и подкласс предмета: 0 расходники, 2 оружие, 4 броня, 5 реагенты, 7 торговые товары; `cls`/`sub` те же числа под старыми именами), `stats` (`GetItemStats`), `tip{локаль}` (строки подсказки). Серые (качество 0), сумки, ключи, квестовые, рубашки и гербовые накидки не сохраняются. В Era у всех расходников подкласс 0: зелье от еды отличает текст подсказки.

Скан: id 1–30000 и 200000–300000, по 400 id за 0,1 с; запросов к серверу не больше 25 за такт, сохранений не больше 150 (чтобы не выкинуло и не просела частота кадров). Сообщение каждые 10 тыс. id. Что сервер не отдал с первого раза, спрашивается ещё раз в конце. Ошибка на одном предмете не останавливает скан.

Чего клиент не отдаёт: полный лут боссов и список наград всех квестов. Источник есть только у того, что аддон видел в игре; у остального в таблице «—».
Подбор под спек делает `gear_import.py` по приоритету статов спека (`content/spec_cheats.py`, `STATS`) и типу брони и оружия класса.
